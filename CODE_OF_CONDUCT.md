# Code of Conduct

The Offering Discovery Protocol community is committed to a professional, respectful, and
collaborative standards-development environment.

## Expected Behavior

- Use clear, constructive technical feedback.
- Assume good faith while holding protocol arguments to a high standard.
- Focus criticism on designs, text, tests, and interoperability impact.
- Respect differences in background, affiliation, and implementation context.
- Take responsibility for mistakes and help maintain a welcoming community.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory conduct.
- Sexualized language or imagery in project spaces.
- Sustained disruption or bad-faith participation intended to derail technical work.
- Publishing private information without permission.
- Conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement

Maintainers may moderate issues, discussions, pull requests, and repository access to preserve a
productive technical environment. Report conduct concerns privately to:

```text
nas@inflowpay.ai
```

Alternatively, contact a repository owner directly through GitHub. Maintainers will protect the
privacy and security of reporters and apply corrective action that is fair and proportionate.
